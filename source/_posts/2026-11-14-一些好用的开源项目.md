最近把手上在用的开源工具重新盘了一遍。

筛的标准只有一条：**装完之后，我第二天还会打开它**。点开截图好看、实际用两次就吃灰的项目太多了，这一轮全砍掉。

最后剩下 5 组，一共 6 个项目——电视那一节是两个工具打配合。从桌面到电视，从工作到玄学，跨度有点大，但每一个都是我自己在用的。

## 一、fly-island：把 iPhone 的「灵动岛」搬到 Windows 桌面

> 项目地址：<https://github.com/flyl1u/fly-island>
> Star：596 ｜ 协议：GPL-3.0 ｜ 平台：Windows 10 / 11

### 它解决的问题

写代码的时候最烦的不是难 bug，是**切窗口**。

Todo 在一个软件里，音乐在另一个，要翻译还得开网页，代码复制粘贴来回跳，中途再来条微信消息——一上午过去，正事没干几行。

fly-island 把这些东西全塞进屏幕顶部一条可折叠的小胶囊里：需要的时候展开，用完收起。作者管这叫「灵动岛」，我觉得更像**桌面版的仪表盘**。

<p align="center">
  <img src="https://bu.dusays.com/2026/11/15/6af9b06ec06b2.png" alt="fly-island 功能演示：微信消息弹到岛上、AI 权限审批、额度环、文件中转" width="100%">
</p>

### 核心能力

- **微信 / QQ / 邮箱消息直接弹到岛上**，一条一张卡片，显示谁发的、说了什么，不用切过去看。微信免打扰的会话只在有人 @ 你 时才提示。
- **AI Agent 状态灯**：Claude Code、Codex 跑到哪一步、要不要你批准改文件，直接在岛上点「允许 / 拒绝」。
- **同步歌词**：收起的岛上只显示当前那句，播到哪算哪。
- **文件中转**：文件拖到岛上暂存，切完窗口再拖出去（只记路径，不复制，不占空间）。
- **图文剪贴板、快捷翻译、待办 / 笔记 / 日历**。

技术上用 Tauri 2 + React 19 + Rust，安装包不大，运行时内存占用也控制得不错。

### 安装

1. 打开 [Releases](https://github.com/flyl1u/fly-island/releases/latest)，下载 `fly-island_x.x.x_x64-setup.exe` 安装。
2. 不放心可以先开[在线预览](https://island.flyliu.org/)，是真实界面 + 演示数据，不用装。
3. 装完按这几步配置才有完整体验：

```text
设置 → 消息      ：开启微信 / QQ 提醒
                  QQ 需要给它「通知访问权限」，且 QQ 本身开着系统通知
                  微信需要电脑版保持登录并开启任务栏提醒
设置 → 邮箱      ：填 IMAP 授权码（不是登录密码），支持 QQ / 163 / 126
设置 → 接入 AI   ：安装 Codex / Claude Code 钩子后，重启对应工具生效
```

> 隐私方面做得比较克制：密钥存 Windows 凭据管理器，邮件只同步邮件头、正文按需读、不改变已读状态，QQ 通知只留内存不落盘。

## 二、Tendedero：截图和剪贴板，全挂到屏幕顶上晒着

> 项目地址：<https://github.com/alejandrobujan/tendedero>
> Star：新项目（Trendshift 日榜 / 周榜双榜）｜ 协议：代码 MIT ｜ 平台：macOS 14+

<!-- <p align="center">
  <img src="https://opengraph.githubassets.com/1/alejandrobujan/tendedero" alt="Tendedero 仓库" width="100%">
</p> -->

### 它解决的问题

先讲个我自己的毛病：桌面上长期堆着几十张截图，全都是「等一下要用」的，结果一张都没用上，后来连哪张是哪张都认不出。

**Tendedero 这个词是西班牙语的「晾衣绳」。** 它做的事跟名字一样朴素——每张截图、每次复制，都挂到屏幕顶部的一根细线上，像晾衣服一样晾着。鼠标移到菜单栏中间，线就滑下来；移开，它自己收回去。

<p align="center">
  <img src="https://bu.dusays.com/2026/11/15/6af9b07265d28.png" alt="Tendedero 效果：一张便签和两张截图挂在菜单栏下方的一条细线上" width="100%">
</p>

### 核心能力

- **截图不再落桌面**。首次启动它会问你要不要接管系统截图：接管之后，右下角的浮动缩略图关掉、不再自动存桌面，截完**立刻挂到线上**。退出应用时原设置自动恢复。
- **录屏也能挂**，缩略图上带播放键，长按可以直接裁剪。
- **复制的文字也挂上去**：一段文字变成一张便签（长得像从备忘录里撕下来的纸），Markdown 会渲染，代码保持原样；复制的链接挂成链接卡；复制的图片照样挂。
- **密码框、密码管理器标记的私密内容、通用剪贴板（跨设备复制）都不会被挂上去。**
- **搜索线上的一切**：<kbd>⌃</kbd><kbd>⌥</kbd><kbd>F</kbd>，用**本机 OCR** 读截图里的字，便签和链接的内容也一起搜。

### 这套手势是我见过最顺的

| 操作 | 效果 |
| --- | --- |
| 点一下 | 复制（便签复制出来还带着格式） |
| 长按 | 打开标注；便签则进入编辑 |
| 拖进应用 | 发送一份副本，原图**仍然留在线上** |
| 拖到文件夹 | 存进去，从线上离开 |
| 右键 → 图钉 | 钉住，之后新截图**不会把它挤走** |
| 拖到废纸篓 / 点叉 | 丢掉；<kbd>⌘</kbd><kbd>Z</kbd> 能反悔 |
| Shift + 点击 | 多选，一次复制 / 删除 / 拖走 |

Finder 里右键图片 → **Hang on Tendedero**，也能直接挂上去。

更难得的是它的克制：**5.1 MB、无账号、无网络、无统计**，OCR 全在本机跑，13 种语言（含简体中文）。

### 安装

Homebrew 一行：

```bash
brew install tendedero
```

或者从 [Releases](https://github.com/alejandrobujan/tendedero/releases/latest) 下载 DMG，拖进「应用程序」。应用已做 Developer ID 签名并通过 Apple 公证，打开不会弹「无法验证开发者」。

想自己编译：

```bash
git clone https://github.com/alejandrobujan/tendedero.git
cd tendedero
scripts/build-app.sh
open build/Tendedero.app
```

> ⚠️ 三个要注意的：
>
> 1. **只有 macOS（14 Sonoma 起），Windows 没有。** 它的核心玩法就是贴着菜单栏顶部，换平台要重做交互。
> 2. 官网 [tendedero.app](https://tendedero.app/?lang=en) 提供了**浏览器在线试玩**，不用装就能看手感，值得先点一下再决定要不要装。
> 3. 代码是 MIT，但**名字和图标不在授权范围内**，拿来二次开发的话要自己起个名字。

## 三、给电视「去广告 + 换桌面」：两个项目打配合

智能电视有两个顽疾，其实是两件事：

1. **开机广告、首页推荐流、一堆用不上的预装**，还偷偷把使用数据传回去；
2. **桌面被厂商锁死**，想换个干净的？不让你换。

下面这两个项目一人管一半。

### 3.1 CleanYourTV —— 把广告服务和预装「关掉」

> 项目地址：<https://github.com/Gathin23/cleanyourtv>
> Star：46,000+（2026 年 10 月 GitHub 周榜第一）｜ 协议：MIT ｜ 平台：Android TV / Google TV

先说清楚它**不是个 App**，而是一套「去广告清单 + 一组工具 + 一个 572 KB 小桌面」的仓库。

原理很朴素：Android 电视和 Android 手机一样有调试桥（ADB）。打开 ADB 之后，用 `pm disable-user` 把厂商的遥测、广告服务、内容推荐行和预装包**禁用**掉——注意是禁用，不是卸载，所以一条命令就能完整还原。

<p align="center">
  <img src="https://bu.dusays.com/2026/11/15/6af9b3304af89.jpg" alt="改造前：Google TV 原厂首页带赞助广告；改造后：CleanYourTV 桌面" width="100%">
</p>

它真正厉害的地方不是代码，是**清单**：472 个机型、129 个品牌、31 种语言，全是网友一台一台试出来的。配套的启动器只有 **572 KB**，纯 Java，为 1 GB 内存的电视优化，没有后台服务、没有联网权限。

这个项目今年 10 月出过圈：作者发了一条给父母家电视做改造的前后对比，860 万浏览；两周内 4.6 万 Star、GitHub 周榜第一，534 家媒体报道。

**安装（大约 15 分钟）**

```text
1. 电视：设置 → 设备偏好设置 → 关于 → 连按「版本号」7 次
        → 返回 → 开发者选项 → 打开「USB 调试」
        （如果有「网络调试 / ADB 调试」也一起打开），电视保持开机
2. 电脑：git clone https://github.com/Gathin23/cleanyourtv
        用 Claude Code / Codex / Gemini CLI 打开这个目录
3. 把仓库里的 PROMPT.md 粘给助手，填上你的电视型号，跟着勾选清单走
```

必须 `git clone`：助手要复用仓库里的 `tools/disable.sh` 和 `launcher/build-and-install.sh`，备份、桌面守护、还原记录都在里面。

不想用 AI 也能手动跑，README 里有完整命令：

```bash
pip install -r tools/requirements.txt
export TV_HOST=192.168.1.50
tools/disable.sh examples/xiaomi-mi-tv-4a/debloat.txt    # 应用清单
tools/restore.sh examples/xiaomi-mi-tv-4a/debloat.txt    # 一键还原
```

> ⚠️ 边界要说清楚：
>
> - **Fire TV 只能做「去广告」那一半**，Fire OS 不让第三方接手桌面。
> - **三星 Tizen、LG webOS、Roku、Vizio、海信 VIDAA 不支持**（没有 ADB），官方给了这几个平台关追踪的替代方案。
> - 少数国行 TCL 拒绝安装任何第三方桌面。
> - 全局开关里把 **USB 调试关掉**再离开，网络 ADB 是明文端口，属于安全风险。

### 3.2 Aerial —— 国产电视能用的干净桌面

> 项目地址：<https://github.com/pengchujin/aerial-tv>
> Star：新项目（国产电视圈口碑项目）｜ 协议：MIT ｜ 平台：Android TV 5.0+，另有 Lite 版支持 4.x

CleanYourTV 的启动器在原生 Android TV 上很顺，但**国产电视固件经常不让你换桌面**：设了默认桌面，待机醒来又蹦回自带的，甚至直接把第三方 App 清掉。

Aerial 就是专治这个的——一个参照 Apple TV 做的桌面，把小米、TCL、雷鸟、创维、海信、索尼、极米这些国产固件的坑基本都踩过一遍。

<p align="center">
  <img src="https://bu.dusays.com/2026/11/15/6af9b06f4bf2c.jpg" alt="原厂桌面：满屏剧集推荐、会员和限免角标" width="49%">
  <img src="https://bu.dusays.com/2026/11/15/6af9b06f5a0ad.jpg" alt="Aerial 首页：玻璃 Dock + 极简桌面" width="49%">
  <br>
  <sub>左：原厂桌面　右：换上 Aerial 之后</sub>
</p>

**它怎么抢回桌面**：用一个无障碍服务盯着前台窗口，原桌面一出现就切回来（只看哪个窗口在前台，**不读屏幕内容**）；被系统清理后再靠通知监听把自己拉起来（**不读通知**）。原生 Android TV 不需要这套，直接设成默认桌面就行。

**功能**

- **底部玻璃 Dock** 放一排常用 App，往下滑是全部应用（连「应用中心」「米家」这类藏起来的系统 App 都在）。
- **长按 OK**：移动、放进文件夹、隐藏、卸载，或者设成「开机时打开」。
- **用手机整理**：扫电视上的二维码，手机上就是一样的图标网格，拖动排序、改名、换图标、加 HDMI 信号源。
- **控制中心**：信号源、网络、音量、亮度、个性化；HDMI 还能选成接的是 Apple TV / PS / Switch / Xbox 的图标。
- **屏保**：Apple TV 那 114 段航拍，支持 4K / 杜比视界；也能换成照片、时钟、手机传的视频。
- **壁纸**：必应每日精选、内置 14 张、手机扫码传的照片和视频。

**安装**

先开 ADB（分品牌方法 README 写得很细），然后一行命令：

```bash
curl -fsSL https://aerial.qust.me/install.sh | KEEP_ADB=1 TV=192.168.1.20 bash
```

电视 IP 在「设置 → 网络 → 已连接的网络」里。`KEEP_ADB=1` 是给小米准备的——它待机后会关掉 ADB，带上这个参数 Aerial 会重新打开，方便以后升级。

不想敲命令也可以：README 里有一份可以直接丢给 AI Agent 的提示词，或者把 APK 拷 U 盘手动装。

还原：

```bash
curl -fsSL https://aerial.qust.me/install.sh | TV=192.168.1.20 bash -s restore
```

> ⚠️ 三句实话：
>
> 1. **开机广告是固件播的，换桌面去不掉**——那得靠上面 CleanYourTV 的禁用清单。
> 2. 支持机型表标了 ⚠️ 和 ❌ 的不少，装之前先查一眼自己的型号。
> 3. 老电视 / 内存小的电视会卡，1.48 起会自动切「流畅」效果（面板纯色、去掉高光）。

### 两个怎么配合用

**先用 CleanYourTV 清掉广告服务和预装**（这一步才是真正把广告关掉），**再装 Aerial 当桌面**（国产固件适配更稳）。

两个项目的共同点是**什么都不卸载**——只做禁用和替换，所以后悔了随时能还原。

## 四、ziwei-doushu：把紫微斗数排盘算法摊开源了

> 项目地址：<https://github.com/Renhuai123/ziwei-doushu>
> Star：18,009 ｜ 协议：代码 MIT / 数据 CC BY 4.0 ｜ 技术栈：TypeScript / Next.js

<!-- <p align="center">
  <img src="https://opengraph.githubassets.com/1/Renhuai123/ziwei-doushu" alt="ziwei-doushu 仓库" width="100%">
</p> -->

### 它是什么

市面上排盘软件一大把，但**排盘规则基本是黑盒**——同一个生辰，不同 App 排出来的盘不一样，你也不知道谁对，因为没人把口径写明白。

这个项目做的是把紫微斗数的排盘引擎**按倪海厦《天纪》体系完整开源**：算法、四化、格局规则、古籍原文，全都摊在 `lib/ziwei/` 里，可读、可查、可改。

作者在 README 里写了一句话，我觉得挺对：

> **算法是公开的传统智慧，不应该被锁在围墙里。**

<p align="center">
  <img src="https://bu.dusays.com/2026/11/15/6af9b06e63a14.png" alt="倪海厦《天纪·紫微斗数》一图看全" width="100%">
</p>

### 技术上有意思的地方

- **真太阳时校正**：按出生地经度算经度差 + 均时差，避免东西向出生的人差出整整一个时辰。
- **中国 1986–1991 年夏令时**判定——这一条能帮不少 80 后把盘排对。
- **闰月四种口径**都实现，可配置，不写死某一派。
- **晚子时换日**策略可切换，按真太阳时判断。
- **星曜亮度 7 档**，且**亮度流派可切换**——不同排盘软件判法不一致，这里做成开关而不是悄悄写死。
- **1100+ 行格局规则库**：紫府同宫、日月并明、七杀朝斗……
- 古籍原文（骨髓赋、紫微斗数全集、全书）按公有领域收录。

另外还开源了一套**样本数据集**：51.8 万条命盘 + 13 维解读，可商用，只要保留来源标注。想拿来微调小模型或者做 RAG 检索的，是个挺有意思的语料。

### 安装 / 本地跑起来

```bash
git clone https://github.com/Renhuai123/ziwei-doushu.git
cd ziwei-doushu

npm install

# 只看排盘可以跳过这一步
cp .env.example .env.local

npm run dev
```

跑测试验证排盘引擎：

```bash
npm run typecheck
npm test
```

> 两个要说清楚的点：
>
> 1. **开源版不含后端 API 路由**。排盘、命盘展示、合盘起盘全在浏览器里用仓库里的引擎完成，**不需要任何 API Key**；只有 AI 解读那几个接口要你自己实现。
> 2. **断语库和商业版界面不开源**。仓库里的界面是一份能跑的 Demo，用来把引擎跑起来、把盘画出来，方便你在它基础上做自己的东西。不想折腾的可以直接用作者自己的线上版 [ouranic.cn](https://ouranic.cn/?from=gh-readme)。

## 五、Sherlock：一个用户名，查遍全网

> 项目地址：<https://github.com/sherlock-project/sherlock>
> Star：111,279 ｜ 协议：MIT ｜ 语言：Python

<p align="center">
  <img src="https://bu.dusays.com/2026/11/15/6af9b06ebd792.png" alt="Sherlock 仓库" width="100%">
</p>

### 它解决的问题

同一个 ID，你可能在 GitHub、Reddit、Instagram、Steam、Pinterest 上都注册过——也可能别人用你的 ID 注册了一堆账号。

Sherlock 的方法很直接：拿一个用户名，去几百个站点挨个试，返回**哪些站点上存在这个账号**，附上直达链接。

它是 OSINT（开源情报）圈子里的老牌工具，十一万 Star，2018 年到现在一直在维护，站点列表每周都有人提交更新。

### 典型输出

```text
$ sherlock johndoe

[*] Checking username johndoe on:
[+] GitHub: https://www.github.com/johndoe
[+] Reddit: https://www.reddit.com/user/johndoe
[+] Steam:  https://steamcommunity.com/id/johndoe
[+] Docker Hub: https://hub.docker.com/u/johndoe
[+] PyPI:   https://pypi.org/user/johndoe
...
```

### 安装

推荐用 pipx，装到独立环境里不污染系统 Python：

```bash
pipx install sherlock-project
```

或者直接克隆源码：

```bash
git clone https://github.com/sherlock-project/sherlock.git
cd sherlock
pip install -r requirements.txt
```

Docker 也行，不折腾环境：

```bash
docker run --rm -it sherlock/sherlock sherlock johndoe
```

### 常用姿势

```bash
# 直接查
sherlock johndoe

# 只查指定站点
sherlock johndoe --site GitHub --site Reddit --site Steam

# 导出结果
sherlock johndoe --csv --output result.csv

# 慢点查，避免被限流
sherlock johndoe --timeout 30
```

> ⚠️ **合规提醒，这条比功能重要**：
> 这个工具只适合用来查**自己的账号**（做账号关联清理、隐私自查），或者**有书面授权的**渗透测试、安全评估、CTF 场景。
> 拿它去扒别人、骚扰、人肉，属于违法，后果自负——这不是免责声明套话，是很多公开案例里真出过事的。
